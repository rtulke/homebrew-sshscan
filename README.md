# homebrew-sshscan

Homebrew tap for [sshscan](https://github.com/rtulke/sshscan) — an SSH algorithm
security scanner for auditing and compliance checking.

This repository contains the Homebrew formula that lets macOS users install and
upgrade sshscan via `brew` without manual dependency management.

## Install

```bash
brew tap rtulke/sshscan
brew install sshscan
```

## Upgrade

```bash
brew upgrade sshscan
```

## Uninstall

```bash
brew uninstall sshscan
brew untap rtulke/sshscan
```

## Source

The sshscan tool itself lives at:
**https://github.com/rtulke/sshscan**

Bug reports and feature requests belong there, not here.
This repository only tracks the Homebrew formula.
